# APS-2-1: 표준 템플릿 라이브러리 — 방향 확정 문서

- **티켓**: APS-2-1
- **분류**: 1중 검증 (단순 문서 작성, 코드 변경 없음)
- **작성 방식**: 메인 직접 (단축 정책)

## 1. 목표 (Why)

APS-1-1 + APS-1-2에서 검증된 패턴을 표준 템플릿으로 코드화하여 향후 유사 작업의 Discovery·플랜·구현 시간을 단축. 신규 작업 시작 시 템플릿을 복사해 채우는 것만으로 표준 보안·품질·검증 절차가 자동 적용되도록 함.

## 2. 사용자 (Who)

- 메인 오케스트레이터 (Claude) — 신규 티켓 발행 시 적용 가능 템플릿 자동 인식
- planner / executor 에이전트 — 템플릿 골격을 따라 plan/구현
- 사용자 — 신규 기능 요청 시 적용된 표준 패턴을 참고

## 3. 범위 (What)

### 포함 (3개 템플릿)
- **mcp-tool-addition.md**: 새 MCP 도구 추가 표준 패턴 (APS-1-1 골격)
  - 도구 등록 위치 (index.ts ListTools + CallTool)
  - 입력 스키마 + `confirmed` 필드 패턴
  - 서비스 클래스 + 단위 테스트 80%+
  - 에러 분류 + 보안 체크리스트
- **external-api-integration.md**: 외부 API 통합 보안 체크리스트
  - `_security-base` 모듈 import 가이드
  - 7가지 보안 패턴 적용 예시
  - 비용 가드 + 화이트리스트
  - 환경변수 / API 키 관리
- **service-implementation.md**: 백엔드 서비스 클래스 표준 골격
  - 의존성 주입 (researchDir 등 옵션 패턴)
  - validateInput → 호출 → classifyError → 결과 반환 흐름
  - 마크다운 결과 저장 (atomicWrite)
  - 단위 테스트 mocking 패턴

### 제외
- 자동 코드 생성 도구 (단순 마크다운 가이드만)
- React/UI 컴포넌트 템플릿 (다른 티켓)

## 4. 제약 (Constraints)

- 마크다운 형식 (Claude Code가 직접 읽음)
- `.claude/templates/` 디렉터리 (직접 편집 허용 영역)
- 각 템플릿 길이 200줄 미만 (가독성)
- 실제 코드 예시 포함 (APS-1-1, APS-1-2 발췌)

## 5. 우선순위 (Priority)

- **P2** (장기 단축 효과 — 다음 유사 작업부터)
