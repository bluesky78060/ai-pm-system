# APS-1-1: Gemini 리서치 자동화 — 방향 확정 문서

- **티켓**: APS-1-1
- **에픽**: MCP 서버 Core
- **작성일**: 2026-05-07
- **수행 주체**: 메인 오케스트레이터 (Claude Opus 4.7) + 사용자

## 1. 목표 (Why)

리서치 기능의 주요 목적은 다음 4가지:

1. **라이브러리/패턴 비교** — 구현 전 외부 라이브러리·아키텍처 패턴·유사 사례 조사
2. **보안/취약점 사전조사** — 변경 영역의 알려진 보안 이슈·OWASP·CVE 조사
3. **기술 트렌드/모범사례** — 최신 트렌드·업계 모범사례·표준 문서 수집
4. **에러/버그 원인 탐색** — 디버깅 시 외부 사례·솔루션 검색

**성공 기준**: Discovery → 리서치 → 플랜 작성 흐름이 한 명령으로 자동 진행되고, 리서치 결과가 플랜 문서에 자동 반영됨.

**측정 지표**: 단위 테스트 커버리지 80%+, Gemini 호출 성공률, 결과 파일 생성 성공률.

## 2. 사용자 (Who)

- **주 사용자**: 메인 오케스트레이터 (Claude) — Discovery 단계 후 자동/수동으로 호출
- **보조 사용자**: 개별 에이전트 (planner, executor) — 작업 중 외부 정보 필요 시 호출
- **시나리오**:
  - 사용자가 Discovery에서 P0/보안/아키텍처 변경 언급 → 자동 리서치 제안
  - 디버깅 작업 중 막힐 때 → 사용자가 명시적 리서치 요청
  - 라이브러리 선택 결정 전 → 비교 리서치
- **페인 포인트**: 현재 외부 정보 조사를 매번 수동으로 web 브라우저에서 하고 결과를 직접 입력해야 함

## 3. 범위 (What)

### 포함
- ai-pm MCP 서버에 `research_with_gemini` 도구 추가
- Gemini API 직접 호출 (`@google/generative-ai` SDK)
- 결과를 `docs/06-research/{ticket-id}-research.md` 파일로 저장
- 마크다운 + 인용(URL) 구조 출력
- 모델: `gemini-2.5-flash` 기본
- CLAUDE.md 워크플로우 3.5단계 (선택 사항) 안내 추가

### 제외 (이번 범위 아님)
- DB 영속화 (`task_research` 테이블 신설 ❌) — 결과는 파일에만 저장
- Web UI 리서치 탭 ❌
- Web Deep Research 모드 (수동 첨부 옵션) ❌
- 다중 모델 병렬 비교 (`/oh-my-claudecode:research`) ❌
- 결과 자동 캐싱 ❌

### MVP 경계
- MCP 도구 1개 (`research_with_gemini`) + 파일 저장 + 환경변수 셋업 안내
- 향후 확장 여지: 캐싱, DB 영속화, Web UI 탭, 다중 모델 비교

## 4. 제약 (Constraints)

- **기술 스택**: 현재 `@ai-pm/mcp-server` 기준 (Node.js, TypeScript, Express)
- **외부 의존**: `@google/generative-ai` SDK (신규 설치)
- **환경변수**: `GEMINI_API_KEY` 수동 설정 필요
- **모델**: `gemini-2.5-flash` (빠르고 저렴, 최신)
- **출력 형식**: 마크다운 + 인용 (제목/요약/세부 섹션 + 참고 URL 목록)
- **호환성**: 기존 MCP 도구 호출 패턴 준수 (`mcp__ai-pm__*`)

## 5. 우선순위 (Priority)

- **P1 (중요)** — 워크플로우 품질 향상 핵심 도구
- **트레이드오프 시 우선 가치**:
  - 안정성 > 속도 (Gemini 실패가 워크플로우 차단하지 않도록)
  - 단순함 > 기능 완비 (MVP 우선, 캐싱·DB는 차후)

## 6. 리스크 (Risk)

| 리스크 | 영향 | 대응 |
|--------|------|------|
| Gemini API 비용 폭주 | 중 | **메인 오케스트레이터 승인 게이트** — 호출 전 사용자 확인 |
| API 키 누락/오설정 | 중 | 명확한 환경변수 안내 + 우아한 에러 메시지 |

| 잘못된 정보 | 중 | 인용 URL 의무 + 사용자가 검증 |
