smart_workflow 상태 머신

workflow-service.ts 기반 태스크 상태 전이. 대괄호 = 액션, 색상 원 = 상태.

backlog / todo
start_work
in_progress
submit_test
testing
테스트 전체 통과 (자동)
review
approve_review · notes 20자+
done ✓
↺ 백트랙: review → request_changes → in_progress  |  testing 실패 시 testing 유지 → complete_fix → 재 testing
가드 규칙 · update_task_status로 testing→review, review→done 직접 전환 금지(서버 차단). submit_test는 build 출력 10자+ 필수, approve_review는 리뷰 notes 20자+ 필수. self-approval(작성자 본인 승인) 금지.
자동 전이 · submit_test 호출 시 in_progress → testing 자동 전환 후, 테스트 전체 통과하면 testing → review로 자동 진행(bypassGuard). 사용자 개입 불필요.
