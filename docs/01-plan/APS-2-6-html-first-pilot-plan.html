1. 요약

본 플랜 문서 자체가 파일럿 산출물. 이 페이지가 브라우저에서 즉시 렌더되는 것이 success criterion #1이다. Anthropic Claude Code 팀(Thariq Shihipar)이 plans/code reviews/design systems/reports 기본 출력을 HTML로 전환 중이며, Karpathy는 진화 경로(text → MD → HTML → diffusion video)를 endorse 했다. 본 프로젝트는 단일 파일럿으로 호환성(hook/critic/사용자 가독성)을 검증한다.

변경 범위

  • 본 플랜 (HTML 단일 파일럿)
  • .claude/templates/plan-template.html
  • .claude/rules/discovery-and-plan.md 갱신

비목표

  • 기존 MD 플랜 일괄 마이그레이션
  • Discovery/Code-review HTML화
  • Hook 매칭 로직 패치 (확인 결과 불필요. 에러 메시지 일관성은 F-005에서 갱신)

3-2. 보안 정책

  • inline JS 금지: <script>, on* 핸들러 금지
  • 외부 CDN 금지: 모든 스타일/폰트 inline CSS 또는 system font
  • 외부 이미지 금지: 필요 시 SVG inline
  • linkable: file:// 더블클릭 동작 보장
